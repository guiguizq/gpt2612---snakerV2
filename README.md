# 🐍 Snake Arcade

Um jogo da cobrinha feito com **HTML, CSS e JavaScript puro**, com visual moderno, controles para teclado e celular e recorde salvo no navegador.

## ▶️ Como jogar

1. Abra `index.html` no navegador ou publique o projeto no GitHub Pages.
2. Clique em **Começar partida**.
3. Mova a cobrinha usando as setas do teclado ou `W`, `A`, `S`, `D`.
4. No celular, use os botões direcionais ou deslize o dedo sobre o tabuleiro.
5. Pressione `Espaço` ou `P` para pausar.

## ✨ Funcionalidades

- Interface responsiva com tema escuro.
- Movimento interpolado para uma animação mais suave.
- Controles por teclado, toque e swipe.
- Sistema de pontuação, níveis e dificuldade progressiva.
- Recorde salvo com `localStorage`.
- Pausa manual e automática ao trocar de aba.
- Sem bibliotecas ou dependências externas.
